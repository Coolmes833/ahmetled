# AhmetLED — kuyumcu ve vitrin aydınlatması sitesi

Tek sayfalık, bağımlılıksız statik site (`index.html`). GitHub Pages üzerinden yayınlanır.

## Düzenleme
- Metinler ve ürünler doğrudan `index.html` içinde; her bölüm `<section id="...">` ile ayrılmıştır.
- **WhatsApp numarası:** `index.html` sonundaki `WA_NUMARA = ""` satırına ülke koduyla rakamları yazın (örn. `905321234567`). Boş kaldığı sürece butonlar iletişim bölümüne götürür.
- Ürün görselleri şimdilik çizim (SVG). Gerçek fotoğraflar için `.art` kutusundaki `<svg>` yerine `<img src="...">` koyun.
- İletişim bilgileri, ürün özellikleri ve çalışma saatleri **örnektir**; gerçek değerlerle değiştirilmelidir.
